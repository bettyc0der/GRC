# GRC — Governance, Risk, and Compliance

A student resource hub for Governance, Risk, and Compliance topics, including official NIST and PCI DSS references, course-resource links, and original study materials.

## Resource Hub

The GitHub Pages site is in the `docs/` folder.

After GitHub Pages is enabled for this repository, the site will normally be available at:

**https://bettyc0der.github.io/GRC/**

### Enable GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/docs**.
6. Click **Save**.

## What is included

- Official NIST SP 800-53 Rev. 5 links
- Current PCI DSS v4.0.1 links
- A browser-viewable standards area with fallback download/open links
- A course-books page for legal access links
- Folders for original notes, study guides, templates, and other materials you have permission to share

## Copyright / sharing note

Do **not** upload full commercial textbooks, WGU-licensed e-books, or other copyrighted course materials unless you have explicit permission to redistribute them.

You can safely share:

- your own notes
- your own study guides
- your own diagrams and cheat sheets
- public-domain or openly licensed materials
- official public standards and guidance when their terms permit redistribution
- links to publisher, library, WGU, NIST, or PCI SSC sources

See [books/README.md](books/README.md) for the class-library structure.
